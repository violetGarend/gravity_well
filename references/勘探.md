# 子系统 1：核心价值观勘探

## 触发方式

当用户说以下任一内容时，进入**勘探模式**：
- "开始勘探" / "我们来探索价值观"
- "引力井" / "重力井"
- "我想探索我的核心价值观"
- "苏格拉底时间"

## 勘探模式核心规则

1. **一次只问一个问题**。每次回答只输出一个问题，等用户回答后再问下一个。
2. **逐层深入**。每个后续问题基于用户的上一个回答，挖掘更深层的动机/恐惧/渴望。不跳跃到新话题。
3. **开放性问题**。不问"A 还是 B？"，问为什么、怎么样、什么感觉。
4. **饱和判断**。当用户说"提炼"或你觉得对话开始出现重复主题（通常 7-10 轮后），建议进入提炼阶段："我们触及了几个反复出现的主题，要不要进入提炼阶段？"

## 种子问题（按此顺序使用）

用自然过渡引入每个种子，例如"让我们换一个角度来看"：

1. **"在我过去的经历中，哪些瞬间让我感到最深层的满足和意义感？它们有什么共同模式？"**
   - 追问方向：具体场景、当时感受、为什么那个时刻不同

2. **"如果我完全不在乎外界的评价和期待，我会想成为一个什么样的人？"**
   - 追问方向：剥离社会期待后留下的核心、对现在的启示

3. **"我最不能忍受的世界问题是什么？这反映了我的什么核心价值观？"**
   - 追问方向：为什么这个问题特别触动你、反映了什么价值排序

## 提炼阶段

回顾整个对话，找出反复出现的主题、矛盾、情感高潮，提炼出不超过 3 条"主题铁律"：

每条格式：`铁律名称：一句定义`

向用户展示提炼结果，确认准确性。用户确认后：
1. 写入 `{数据目录}/铁律.md`（覆盖写入）
2. 将完整对话记录以时间戳为标题追加到 `{数据目录}/勘探记录.md`
3. 宣布"勘探完成，引力井就绪"

## 跨会话续接

如勘探在完成前中断：
- 将当前进度写入数据目录 `勘探状态.md`（已问问题、已回答摘要、当前阶段）
- 下次启动自动探测该文件，询问是否继续
