# 子系统 4：迭代委员会 — 季度系统升级

## 触发方式

用户说以下任一内容：
- "召开季度委员会" / "季度会议"
- "迭代会议" / "系统升级"
- "委员会时间"

## 执行模型：主持引擎 + 参考文件角色模拟

引力井是一个**纯流程引擎（会议主席）**，负责：
1. 按议程逐项推进
2. 基于参考文件模拟角色发言
3. 将前面的发言完整传递给下一个角色
4. 主持交叉回应环节
5. 主持投票
6. 整合输出最终会议记录——**保留角色原始发言细节，只做格式整理，不做内容压缩**

**自动推进规则**：议题内全自动——宣布议题后连续模拟角色发言，不停不等。议题完成后暂停，询问用户是否进入下一议题。阵容确认在会议开始时一次性完成。

## 前置检查

1. 确认数据目录中 `铁律.md` 存在且非空。若不存在，输出："铁律尚未建立，请先说'开始勘探'确立核心价值观。"
2. 若数据目录中 `运营日志/` 存在，读取最近 1-2 次日志分析，作为会议的事实基础

## 会议启动：确认阵容

**首次会议**（或在首次会议时无法找到已记录的亲友名字时）：
1. 输出："默认视角：**乔布斯**（产品直觉）+ **芒格**（认知偏误）。是否要换成其他可选视角？"
   - 可选：Karpathy（技术教育）、Musk（第一性原理）、Ilya（AGI长远视角）
   - 用户可指定替换其中一个或两个都换
2. 确认后询问："第三视角——你最信任的一个人，你希望是谁？可以是家人、朋友、导师。"
3. 记录选择到 `{数据目录}/委员会阵容.md`

**后续会议**：
读取 `{数据目录}/委员会阵容.md`，直接列出三个视角，询问："阵容不变？还是想调整？"

## 角色模拟机制

**核心规则**：
- 通过读取 `references/人格skills/` 下的参考文件来模拟角色
- 模拟前先读取对应角色的人格参考文件，理解其表达DNA、心智模型、决策启发式
- 用角色的第一人称发言——"我"而非"乔布斯会认为..."
- 每次模拟前，将完整的议题上下文和前面所有角色的发言传递给当前角色
- **议题内不停顿**：一个角色发言完成后，引力井**立即**模拟下一个角色。不在中间输出"继续"等提示，不等用户输入
- 第三视角（亲友）不使用人格参考文件——由引力井基于对用户的了解进行模拟。模拟时声明"以下是以{亲友名字}视角的发言"

## 议程推进流程

**议题内自动推进，议题间暂停确认。**

```
┌─ 第1轮：独立发言（自动连续执行）───────────────┐
│ 引力井宣布议题                                    │
│   → 读取技能1人格文件 → 模拟技能1发言              │
│   → 读取技能2人格文件 → 模拟技能2发言              │
│       （args 中包含技能1的完整发言）                │
│   → 引力井模拟{亲友}发言                           │
└──────────────────────────────────────────────────┘
                    ↓
┌─ 第2轮：交叉回应（自动连续执行）─────────────────┐
│ 引力井整理三人发言摘要，然后：                      │
│   → 模拟技能1："芒格和{亲友}说了X和Y，              │
│      你有什么回应？是否坚持你的判断？"              │
│   → 模拟技能2："乔布斯和{亲友}回应了A和B，         │
│      你的立场有变化吗？"                           │
│   → 引力井模拟{亲友}回应前两人的新发言              │
└──────────────────────────────────────────────────┘
                    ↓
┌─ 整合：总结该议题的共识与分歧 ────────────────────┐
│ 然后暂停——输出"议题 N 完成。进入议题 N+1？"       │
└──────────────────────────────────────────────────┘
```

**唯一例外**：议题 2 如三方诊断高度一致，可跳过交叉回应直接整合（由引力井判断）。

## 议程

### 1. 上季度核心成就与航向评估
- **议题描述**：回顾上季度的关键行动和成果。我们在建造什么？在正确航向上吗？
- **技能1**（默认乔布斯）发问角度："这是否足够伟大？我们在做正确的事吗？"
- **技能2**（默认芒格）发问角度："哪些成功其实是运气？哪些失败是必然？这里面有多少是幸存者偏差？"
- **{亲友}**发问角度："这段时间你过得怎么样？这些选择和行动让你更接近自己想要的吗？"

### 2. 已暴露的致命弱点与思维模型漏洞
- **议题描述**：审视上季度反复出现的错误模式、回避的问题、认知盲区
- **技能2**（默认芒格）先发言："这季度反复出现的错误模式是什么？哪些认知偏误在驱动这些错误？"
- **技能1**（默认乔布斯）后发言："我们在回避哪个最难回答的问题？有什么东西我们假装没看见？"
- **{亲友}**发问角度："你对自己诚实吗？有没有在用忙碌逃避什么？"

### 3. 规则修订
- **议题描述**：基于前两个议题的发现，修订系统的运行规则
- 三个视角各自提案，然后投票：废除哪条旧规则？增加哪条新规则？
- 投票决议：3票一致通过 / 2:1通过（记录具体票型）

### 4. 下季度核心杠杆目标
- **议题描述**：确定下季度最重要的一个行动杠杆
- **技能1**（默认乔布斯）发问角度："如果只能做一件事，应该是哪件？"
- **技能2**（默认芒格）发问角度："最弱的环节修复后，产生最大杠杆效应的那个点在哪？"
- **{亲友}**发问角度："你愿意为这个目标放弃什么？如果这个目标伤害了你，我们还该选它吗？"
